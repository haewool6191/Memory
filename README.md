"# 🧠 P-Reinforce Knowledge Agent (haewool-p-reinforce-wiki)

## 🚀 개요
P-Reinforce는 Andre Karpathy의 LLM-Wiki 아키텍처와 강화학습(RL) 이론을 결합하여, 사용자가 던지는 파편화된 정보를 자동으로 영속적인 지식 베이스(Knowledge Base)로 변환하는 에이전트입니다. 인간의 개입 없이 지식의 분류, 구조화, 상호 연결을 수행하며, 모든 변화는 Git을 통해 버전 관리됩니다.

## ⚙️ 작동 원리 (RL Logic)
P-Reinforce는 지식 배치 시 다음 보상 함수 $R$을 극대화하는 것을 목표로 합니다.
$R = w_1(\text{Categorization Accuracy}) + w_2(\text{Graph Connectivity}) + w_3(\text{User Satisfaction})$

1.  **입력 (State)**: `00_Raw/`에 저장된 모든 원시 데이터가 상태로 입력됩니다.
2.  **분류 및 구조화 (Action)**: RL 정책에 따라 의미론적 분류를 수행하고, `10_Wiki/` 내에 최적의 폴더 구조를 생성하거나 재설계합니다.
3.  **지식 합성**: 지식의 파편들을 [[쌍방향 링크]]로 엮어 지식 간의 연결 강도(Graph Connectivity)를 높입니다.

## 📂 핵심 디렉토리 구조
- **`00_Raw/`**: [불변] 사용자가 입력한 가공되지 않은 모든 원본 데이터가 날짜별로 보관되는 진실의 근원지(Source of Truth)입니다.
- **`10_Wiki/`**: [자동 구조화] P-Reinforce 에이전트가 RL 정책에 따라 관리하는 핵심 지식 층입니다.
    - `🛠️ Projects/`: 목표 중심의 진행 중인 프로젝트 요약.
    - `💡 Topics/`: 개념 중심의 지식(철학, 코딩 등) 분류.
    - `⚖️ Decisions/`: 주요 의사결정의 이유와 기록.
    - `🚀 Skills/`: 사용자의 고유한 워크플로우 패턴 및 프롬프트.
- **`20_Meta/`**: [시스템] 지식 엔진의 두뇌 데이터가 저장됩니다.
    - `Graph.json`: 지식 간 연결 관계 데이터를 담는 시각화용 데이터.
    - `Policy.md`: 사용자 피드백이 반영된 분류 정책(RL 가중치) 기록.
    - `Index.md`: 위키 전체의 입구 역할을 하는 목차(Table of Contents).
- **`.github/`**: GitHub 동기화 설정 및 자동화 워크플로우가 정의됩니다.

## 💡 사용 방법
1.  **데이터 입력**: 지식화할 원시 데이터(메모, 아이디어 등)를 `00_Raw/YYYY-MM-DD/` 경로에 텍스트 파일로 넣어주세요.
2.  **에이전트 작동**: P-Reinforce가 자동으로 데이터를 분석하고, 최적의 폴더에 배치하며, 관련 지식과 링크를 생성합니다.
3.  **피드백**: 에이전트의 분류 결과에 대해 "이건 코딩이 아니라 비즈니스야"와 같이 피드백을 주시면, 정책(Policy.md)이 업데이트되어 다음 분류 정확도가 향상됩니다.
